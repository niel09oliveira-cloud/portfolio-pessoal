# 🚀 Daniel Dev — Portfólio

Um portfólio moderno e interativo desenvolvido para apresentar minhas habilidades como desenvolvedor Front-End.

## 🌐 Sobre o projeto

Este projeto foi criado com foco em:
- Experiência visual moderna
- Animações suaves
- Interface interativa
- Código limpo e organizado

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Canvas API
- Intersection Observer

## ✨ Funcionalidades

- 🎯 Cursor personalizado interativo
- 🎨 Animações suaves ao rolar a página
- 🌌 Background animado com partículas
- 📊 Barras de habilidades animadas
- 🧊 Efeito 3D no card de apresentação
- 📱 Design responsivo
